# ASC Magic Reds Uitwedstrijd Inschrijvingssysteem

---

## Beschrijving

Dit project is een webapplicatie, speciaal ontwikkeld voor de **ASC Magic Reds**, één van de officiële supportersclubs van **RAFC**. Het hoofddoel van deze applicatie is het stroomlijnen en automatiseren van het inschrijvingsproces voor uitwedstrijden.

Traditioneel moesten leden zich handmatig inschrijven bij de voorzitter, die vervolgens op basis van beschikbare kaarten en een puntenlijst handmatig moest bepalen wie er mee mocht. Dit systeem elimineert die handmatige processen, waardoor inschrijven makkelijker wordt voor de leden en het beheer efficiënter voor het bestuur.

**Belangrijk:** Om de exclusiviteit voor clubleden te waarborgen, is toegang tot de functionaliteiten van de site alleen mogelijk voor leden wiens e-mailadres vooraf door de voorzitter is toegevoegd aan het systeem. De authenticatie en autorisatie hiervoor worden beheerd via **Auth0**, wat zorgt voor een veilige en betrouwbare inlogervaring. Ongeautoriseerde gebruikers worden bij een poging tot toegang geweigerd en zien een scherm dat aangeeft dat ze geen toegang hebben.

Deze website is online gezet via **Render** en is te bezoeken via de volgende URL: [ascmagicreds.onrender.com](https://ascmagicreds.onrender.com).
